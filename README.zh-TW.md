<a id="what-is-included"></a>
## 項目包含什麼

- **52 個完整提示詞：** 每條都包含模式、固定人物或物件、空間關係、分時段動作、表演、聲音和需要避免的問題。
- **13 個製作分類：** 涵蓋電影、對白、參考控制、編輯、產品、直播、使用者風格內容、汽車、工業、動作、視覺特效、動畫、垂直螢幕短劇、社交傳播、動態圖形、轉場、聲畫同步、美食、旅行、學習、寵物、遊戲及可重複使用製作素材。
- **四種控制方法：** 文字探索、圖生影片、首尾影格過渡，以及主體和參考圖一致性。
- **Kling 3.0 已有文件說明的五種原生對白語言：** 中文、英文、日語、韓語和西班牙語，包含混合語言範例；完整版 4.0 宣布將支援更多語言。
- **15 種項目語言：** 提供本地化導航和使用說明，並明確區分文件語言與模型語音支援範圍。
- **六張本地圖片：** 包括 Flyne AI 封面和五張場景參考圖，詳見 [素材清單](assets/images/README.md).
- **製作指導：** 畫幅規劃、鏡頭空間關係、參考素材使用權、聲音時間軸、修改記錄、權利查核及發布前檢查。
- **Flash 創作者案例：** 18 個帶有來源的 X 案例（10 個繼承、8 個新增）、4 個繼承練習、6 個 Flyne AI 練習及自行車燈入門提示詞。
- **Flyne AI 使用說明：** 介紹網頁創作步驟，並提醒生成前確認所選模型。

<a id="model-status-and-compatibility"></a>
## 模型版本與相容性

Kling 4.0 已公佈。目前可體驗的 Flash 與計劃推出的完整版開放情況不同，修改提示詞時請以帳戶實際選擇的模型為準。

| 專案 | 已核驗狀態 | 本庫的使用原則 |
|---|---|---|
| Kling 4.0 Flash | **搶先體驗已於 2026 年 9 月 28 日開放** ，針對 Ultra 年卡會員 | 以帳戶實際開放的功能為準，不套用完整版 4.0 的全部參數 |
| 完整版 Kling 4.0 | **宣布將於 2026 年 10 月推出**，具體日期未公佈 | 已公佈功能仍需在完整版上線後驗證 |
| 單次生成時長 | Video 3.0 最長 **15秒**；完整版 4.0： **宣布最長 30 秒** | 現有 52 個提示詞時長為 5–15 秒，只有所選模型支援較長影片時才擴展時間軸 |
| 多關鍵影格與參考控制 | 完整版 4.0 宣布最多支持 **10 張關鍵幀** 和 **15 項多模態參考** | 為每份參考素材和關鍵影格指定用途，並確認目前模式支援這些功能 |
| 完整版 4.0 畫面與聲音 | 最高 **4K / 10-bit HDR**，並宣布支援立體聲及更準確的口型同步 | 不同模式或套餐的輸出選項可能不同，請核對生成設置 |
| Kling 3.0 視訊輸出 | 官方指南列出 720p/1080p 模式；快手宣布 **推出原生 4K** ，日期為 2026-08-19 | 記錄實際模型、平台、模式和日期；不同入口的支援情況可能不同 |
| 多鏡頭 | 文件說明支援自動和自訂多鏡頭 | 每鏡寫清時間、景別、動作和運鏡路線 |
| 人物與主體一致性 | 文件說明支援首幀與綁定主體參考 | 不同鏡頭重複使用同一人物或物件名稱及固定特徵 |
| 原生音訊 | 對白、環境聲與音效 | 按發言角色和時間節點安排聲音 |
| Kling 3.0 已核驗的對白語言 | 中文、英文、日文、韓文和西班牙語 | 完整版 4.0 宣布擴展語言、口音和方言支援；仍需測試所選模式 |
| 三人及以上對白 | 文件說明支援多人指代 | 多人場景固定姓名、座位、服裝及發言順序 |
| 文字保留 | 文件說明已改進參考圖文字保留 | 以已確認的產品包裝圖作參考，並逐幀檢查 |
| 可靈官方 API | Kling AI 表示 **4.0 API 接入計劃於 10 月推出** | 不預填尚未發布的 4.0 模型名稱、價格或請求參數 |
| Flyne AI 支援情況 | 預計支援時間為 **2026 年 10 月**，具體日期另行公佈。目前表單選擇 **Kling 3.0 Turbo** | 產生前確認模型；目前未核驗穩定的 4.0 服務 |

資料核驗於 2026 年 9 月 29 日： [Kling AI 4.0公告](https://sg.linkedin.com/company/kling-ai-api), [Kling 4.0 更新說明](https://kling.ai/release-note/release-notes/Kling_4?type=dialog), [Kling Video 3.0 官方指南](https://app.klingai.com/cn/quickstart/klingai-video-3-model-user-guide), [快手3.0原生4K更新](https://ir.kuaishou.com/news-releases/news-release-details/kuaishou-technology-announces-second-quarter-and-interim-2026)，以及 [Flyne AI 使用指南](docs/FLYNE.md).

**Flash 入門提示詞（15 秒，9:16）：** 這條未實測練習不計入 52 條主提示詞，參考的是上述 *測試方法* ，並非複製 X 作者的提示詞。請只使用所選 Flash 模式實際開放的功能。

```text
[主體 / 參考]
維修台上放著一盞無品牌的小型充電自行車燈。如提供參考圖，只用它固定車燈形狀、霧面石墨色外殼和唯一的琥珀色開關。全程只有一盞車燈。

[場景 / 運鏡]
傍晚安靜的腳踏車修理鋪。鏡頭連續近距離跟隨，從修理師雙手移向車燈，再移向車把。採用窗外自然光，不切鏡，不讓物體瞬移。

[時間安排]
0–4s：修理師把未亮的車燈放在車把旁，同時展示雙手與安裝支架。
4–8s：她將車燈扣入支架。聽到卡扣鎖定聲後，大拇指才按下琥珀色開關。
8–12s：車燈亮起一次，照亮前輪和一小塊地面。鏡頭緩慢側移，展示光束。
12–15s：她鬆開車把，車燈保持固定。最後穩定停留在自行車和車燈上。

[聲音 / 限制]
修理鋪環境聲、一次扣環聲、一次開關聲；無對白、無音樂。保持車燈形狀、手的數量、安裝位置和光線方向。不出現品牌文字、多餘車燈或無緣由的切鏡。
```

對 Flash， **簡短提示詞** 和 **較長但結構清楚的提示詞** 都值得測試。關鍵在於每句話是否明確影響畫面或聲音。只有在記錄所選模式、時長、參考素材和結果後，才能將提示詞標為「已測試」。

<a id="what-makes-a-strong-kling-video-prompt"></a>
## 怎麼寫好 Kling 影片提示詞？

有效的提示詞像一份簡明拍攝說明，應寫清動作和鏡頭，而不是堆砌形容詞。

```text
[輸出]
長度、畫幅、一鏡到底或多鏡頭，以及預期成片風格。

[參考素材的用途]
圖 1 固定人物身分；圖 2 固定產品形狀；動作參考只負責運動。

[不變的特徵]
指定主體名稱，固定臉部、髮型、輪廓和服裝；固定產品或道具的形狀、材質和顏色。

[場景]
地點、時間、天氣、現場光源及人物及物體的起始位置。

[分時段鏡頭]
0–{x}s－景別、角度和運鏡路線；一個主要動作及其物理反應。
{x}–{y}s－下一個動作節點；一個主要動作，交代結果並安排結尾畫面。

[表演與實體表現]
視線、呼吸、手部、重量、慣性、接觸、布料、液體及環境反應。

[聲音]
指定發言角色、準確台詞、語言、語調、環境聲、同步音效及音樂開始和結束的時間。

[連續性 / 避免事項]
寫明絕對不能改變的內容；避免人物變臉、重複物件、錯誤文字、標誌和浮水印。
```

閱讀 [Kling 影片提示詞指南](docs/PROMPT-GUIDE.md) ，了解完整方法及逐步修改的順序。

## 語言與在地化

本項目提供與英文對齊的 README 翻譯，共 **15 種語言**:

- 英文、簡體中文、繁體中文、日文、韓文；
- 西班牙語、法語、德語、巴西葡萄牙語和義大利語；
- 阿拉伯語、俄語、印尼語、泰語和越南語。

主提示詞檔案保留英文，以免複雜時間軸和運鏡指令在多份翻譯中出現偏差。各語言 README 均與英文首頁對齊，包含模型狀態、X 案例、提示詞模板、圖文精選、完整目錄、檢查清單、常見問題、介面推薦和聯盟合作。連結所指向的 52 個主提示詞仍為英文；本頁的兩個提示詞代碼區塊已翻譯。詳見 [語言支援表與翻譯規則](docs/LANGUAGES.md).

> 文檔語言不等於模型原生語音支援。 Kling 3.0 已核驗的對白語言為中、英、日、韓、西。完整版 4.0 宣布將擴展多語言和口音支援；發布前仍應核對所選模式並檢查生成語音。

<a id="image-to-video-checklist"></a>
## 圖生影片檢查清單

- 固定人物身分、服裝、產品形狀、物體數量、構圖和主光方向。
- 每份參考素材只分配一個主要用途，不要求所有參考圖同時控制一切。
- 分別描述主體、環境和鏡頭的運動。
- 寫清鏡頭起點、路線、速度與最終停止位置。
- 保持手部接觸、重量、慣性、反射和陰影合理。
- 結尾預留一至兩秒，讓動作減速並停在可用畫面上。
- 將對白、環境聲、動作音效和音樂分層安排。
- 使用原創或授權的人物、產品、音樂、鏡頭和地點。

<a id="kling-prompt-faq"></a>
## Kling 提示詞常見問題

<a id="what-is-a-kling-video-prompt"></a>
### 什麼是 Kling 影片提示？

好的 Kling 提示詞是一份簡明拍攝說明，寫清輸出要求、參考用途、固定特徵、空間關係、分時段動作、運鏡、表演、物理反應、聲音及需要避免的具體問題。

<a id="should-i-use-text-to-video-or-image-to-video"></a>
### 應該選擇文生影片還是圖生影片？

從創意或腳本探索畫面時用文生影片。需要保持產品、人物、插畫、構圖或首格特徵時用圖生影片。結尾和開頭同樣重要時，可用首尾幀控制。

<a id="how-do-i-keep-a-person-or-product-consistent"></a>
### 怎樣保持人物或產品一致？

先確定主要人物或產品，寫明運動前後不能變化的特徵；支持參考材料的模式中綁定對應圖片，並明確不改變設計、零件數量、標籤或人物身份。先測試一致性，再加入複雜效果。

<a id="can-prompts-be-written-in-different-languages"></a>
### 可以使用不同語言寫提示詞嗎？

可以。本專案提供 15 種語言的完整 README。 Kling 3.0 文件已確認支援中、英、日、韓、西原生對白。寫清語言、角色、語氣和台詞歸屬，並核對發音與措詞。

<a id="are-the-prompts-free-to-use"></a>
### 這些提示詞可以免費使用嗎？

本倉庫採用 [MIT](LICENSE)。產生結果也可能涉及人物、聲音、音樂、商標、參考圖、地點、宣傳內容及模型平台的獨立使用規定。

<a id="is-kling-40-available-now-and-can-it-generate-30-seconds"></a>
### Kling 4.0現在可以用嗎，能生成30秒嗎？

**Kling 4.0 Flash 已開放搶先體驗** ，自 2026 年 9 月 28 日起對象 Ultra 年卡會員。官方計劃於 10 月推出完整版 4.0 及 API 接入，尚未公佈具體日期。其 **最長 30 秒是完整版已宣布的單次生成能力**，不能推斷當前 Flash 或所有第三方平台都支援。現有 52 個提示詞長度為 5–15 秒，可在完整版控制項開放後擴展時間軸。
