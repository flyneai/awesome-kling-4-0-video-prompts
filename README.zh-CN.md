<a id="what-is-included"></a>
## 项目包含什么

- **52 条完整提示词：** 每条都包含模式、固定人物或物体、空间关系、分时段动作、表演、声音和需要避免的问题。
- **13 个制作分类：** 覆盖电影、对白、参考控制、编辑、产品、直播、用户风格内容、汽车、工业、动作、视觉特效、动画、竖屏短剧、社交传播、动态图形、转场、声画同步、美食、旅行、学习、宠物、游戏及可复用制作素材。
- **四种控制方法：** 文字探索、图生视频、首尾帧过渡，以及主体和参考图一致性。
- **Kling 3.0 已有文档说明的五种原生对白语言：** 中文、英语、日语、韩语和西班牙语，包含混合语言示例；完整版 4.0 宣布将支持更多语言。
- **15 种项目语言：** 提供本地化导航和使用说明，并明确区分文档语言与模型语音支持范围。
- **六张本地图片：** 包括 Flyne AI 封面和五张场景参考图，详见 [素材清单](assets/images/README.md).
- **制作指导：** 画幅规划、镜头空间关系、参考素材使用权、声音时间轴、修改记录、权利核查及发布前检查。
- **Flash 创作者案例：** 18 个带来源的 X 案例（10 个继承、8 个新增）、4 条继承练习、6 条 Flyne AI 练习及自行车灯入门提示词。
- **Flyne AI 使用说明：** 介绍网页创作步骤，并提醒生成前确认所选模型。

**Flash 入门提示词（15 秒，9:16）：** 这条未实测练习不计入 52 条主提示词，参考的是上述 *测试方法* ，并非复制 X 作者的提示词。请只使用所选 Flash 模式实际开放的功能。

```text
[主体 / 参考]
维修台上放着一盏无品牌的小型充电自行车灯。如提供参考图，只用它固定车灯形状、哑光石墨色外壳和唯一的琥珀色开关。全程只有一盏车灯。

[场景 / 运镜]
傍晚安静的自行车修理铺。镜头连续近距离跟随，从修理师双手移向车灯，再移向车把。采用窗外自然光，不切镜，不让物体瞬移。

[时间安排]
0–4s：修理师把未亮的车灯放在车把旁，同时展示双手与安装支架。
4–8s：她将车灯扣入支架。听到卡扣锁定声后，拇指才按下琥珀色开关。
8–12s：车灯亮起一次，照亮前轮和一小块地面。镜头缓慢侧移，展示光束。
12–15s：她松开车把，车灯保持固定。最后稳定停留在自行车和车灯上。

[声音 / 限制]
修理铺环境声、一次卡扣声、一次开关声；无对白、无音乐。保持车灯形状、手的数量、安装位置和光线方向。不出现品牌文字、多余车灯或无缘由的切镜。
```

对 Flash， **简短提示词** 和 **较长但结构清楚的提示词** 都值得测试。关键是每句话是否明确影响画面或声音。只有记录所选模式、时长、参考素材和结果后，才能将提示词标为“已测试”。

<a id="what-makes-a-strong-kling-video-prompt"></a>
## 怎样写好 Kling 视频提示词？

有效的提示词像一份简明拍摄说明，应写清动作和镜头，而不是堆砌形容词。

```text
[输出]
时长、画幅、一镜到底或多镜头，以及预期成片风格。

[参考素材的用途]
图 1 固定人物身份；图 2 固定产品形状；动作参考只负责运动。

[保持不变的特征]
指定主体名称，固定面部、发型、轮廓和服装；固定产品或道具的形状、材质和颜色。

[场景]
地点、时间、天气、现场光源及人物和物体的起始位置。

[分时段镜头]
0–{x}s——景别、角度和运镜路线；一个主要动作及其物理反应。
{x}–{y}s——下一个动作节点；一个主要动作，交代结果并安排结尾画面。

[表演与物理表现]
视线、呼吸、手部、重量、惯性、接触、布料、液体及环境反应。

[声音]
指定发言角色、准确台词、语言、语气、环境声、同步音效及音乐开始和结束的时间。

[连续性 / 避免事项]
写明绝不能变化的内容；避免人物变脸、重复物体、错误文字、标志和水印。
```

阅读 [Kling 视频提示词指南](docs/PROMPT-GUIDE.md) ，了解完整方法及逐步修改的顺序。

<a id="image-to-video-checklist"></a>
## 图生视频检查清单

- 固定人物身份、服装、产品形状、物体数量、构图和主光方向。
- 每份参考素材只分配一项主要用途，不要求所有参考图同时控制一切。
- 分别描述主体、环境和镜头的运动。
- 写清镜头起点、路线、速度与最终停止位置。
- 保持手部接触、重量、惯性、反射和阴影合理。
- 结尾预留一至两秒，让运动减速并停在可用画面上。
- 将对白、环境声、动作音效和音乐分层安排。
- 使用原创或授权的人物、产品、音乐、镜头和地点。

<a id="kling-prompt-faq"></a>
## Kling 提示词常见问题

<a id="what-is-a-kling-video-prompt"></a>
### 什么是 Kling 视频提示词？

一条好的 Kling 提示词是一份简明拍摄说明，写清输出要求、参考用途、固定特征、空间关系、分时段动作、运镜、表演、物理反应、声音及需要避免的具体问题。

<a id="should-i-use-text-to-video-or-image-to-video"></a>
### 应该选择文生视频还是图生视频？

从创意或脚本探索画面时用文生视频。需要保持产品、人物、插画、构图或首帧特征时用图生视频。结尾和开头同样重要时，可用首尾帧控制。

<a id="how-do-i-keep-a-person-or-product-consistent"></a>
### 怎样保持人物或产品一致？

先确定主要人物或产品，写明运动前后不能变化的特征；支持参考素材的模式中绑定对应图片，并明确不改变设计、零件数量、标签或人物身份。先测试一致性，再加入复杂效果。

<a id="can-prompts-be-written-in-different-languages"></a>
### 可以使用不同语言写提示词吗？

可以。本项目提供 15 种语言的完整 README。Kling 3.0 文档已确认支持中、英、日、韩、西原生对白。写清语言、角色、语气和台词归属，并核对发音与措辞。

<a id="are-the-prompts-free-to-use"></a>
### 这些提示词可以免费使用吗？

本仓库采用 [MIT 许可证](LICENSE)。生成结果还可能涉及人物、声音、音乐、商标、参考图、地点、宣传内容及模型平台的独立使用规定。

<a id="is-kling-40-available-now-and-can-it-generate-30-seconds"></a>
### Kling 4.0现在可以用吗，能生成30秒吗？

**Kling 4.0 Flash 已开放抢先体验** ，自 2026 年 9 月 28 日起面向 Ultra 年卡会员。官方计划于 10 月推出完整版 4.0 及 API 接入，尚未公布具体日期。其 **最长 30 秒是完整版已宣布的单次生成能力**，不能推断当前 Flash 或所有第三方平台都支持。现有 52 条提示词时长为 5–15 秒，可在完整版控制项开放后扩展时间轴。
