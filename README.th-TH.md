## สิ่งที่รวมอยู่ด้วย

- **พรอมต์ที่สมบูรณ์ 52 รายการ ไม่ใช่แฟรกเมนต์บรรทัดเดียว:** ข้อความแจ้งแต่ละรายการประกอบด้วยโหมดโมเดล ลักษณะตัวละครและวัตถุคงที่ เค้าโครงฉาก การกระทำตามกำหนดเวลา การแสดง เสียง และข้อผิดพลาดที่ควรหลีกเลี่ยง
- **คอลเลกชันการผลิตสิบสาม:** ภาพยนตร์, บทสนทนา, การควบคุมการอ้างอิง, การตัดต่อ, ผลิตภัณฑ์, สตรีมสด, UGC, ยานยนต์, อุตสาหกรรม, แอ็คชั่น, VFX, แอนิเมชั่น, ละครแนวตั้ง, โซเชียลไวรัล, กราฟิกเคลื่อนไหว, การเปลี่ยนภาพ, การซิงค์เสียง, อาหาร, การเดินทาง, การเรียนรู้, สัตว์เลี้ยง, เกม และแผ่นการผลิตที่นำมาใช้ซ้ำได้
- **สี่กลยุทธ์การควบคุม:** การค้นพบที่นำโดยข้อความ รูปภาพเป็นวิดีโอ การเปลี่ยนเฟรมเริ่มต้น/สิ้นสุด และความสอดคล้องขององค์ประกอบ/การอ้างอิง
- **ภาษาบทสนทนาพื้นเมืองของ Kling 3.0 ห้าภาษา:** จีน อังกฤษ ญี่ปุ่น เกาหลี และสเปน รวมถึงตัวอย่างภาษาต่างๆ เวอร์ชันเต็ม 4.0 สัญญาว่าจะรองรับภาษาที่กว้างขึ้น
- **15 ภาษาของโครงการ:** การนำทางที่แปลเป็นภาษาท้องถิ่นและคำแนะนำการเริ่มต้นอย่างรวดเร็ว โดยมีความแตกต่างที่โปร่งใสระหว่างเอกสารประกอบและการสนับสนุนคำพูดของโมเดล
- **เนื้อหาภาพท้องถิ่นหกรายการ:** หน้าปก Flyne AI และภาพอ้างอิงฉาก 5 ภาพ บันทึกไว้ใน [รายการสินทรัพย์](assets/images/README.md).
- **คำแนะนำการผลิต:** อัตราส่วนภาพ ตำแหน่งกล้อง สิทธิ์ในข้อมูลอ้างอิง ไทม์ไลน์ของเสียง บันทึกการแก้ไข และตรวจสอบก่อนเผยแพร่
- **รายการเฝ้าดูผู้สร้าง Flash:** X เคสที่เชื่อมโยง 18 รายการ (สืบทอดมา 10 รายการ เพิ่ม 8 รายการ) แบบฝึกหัดที่สืบทอดมา 4 รายการ แบบฝึกหัด Flyne AI หกรายการ และอุปกรณ์สตาร์ทไฟจักรยาน
- **บันทึกขั้นตอนการทำงานของ Flyne AI:** เวิร์กโฟลว์ของเบราว์เซอร์ที่ตรวจสอบโมเดลที่เลือกก่อนสร้าง

```text
เสียงพื้นหลังเวิร์คช็อปที่เงียบงัน การคลิกคลิปยึดหนึ่งครั้ง และการคลิกสวิตช์หนึ่งครั้ง ไม่มีคำพูดหรือดนตรี รักษารูปทรงโคมไฟ จำนวนเข็ม ตำแหน่งการติดตั้ง และทิศทางของไฟให้ไม่เปลี่ยนแปลง ไม่มีชื่อแบรนด์ โคมไฟเพิ่มเติม หรือการตัดที่ไม่สามารถอธิบายได้
```

สำหรับแฟลช ก **คำสั่งสั้น** และก **คำสั่งยาวที่มีโครงสร้างชัดเจน** คุ้มค่ากับการทดสอบ: ปัจจัยในการตัดสินใจคือทุกประโยคควบคุมการตัดสินใจที่มองเห็นหรือได้ยิน บันทึกโหมด ระยะเวลา ข้อมูลอ้างอิง และผลลัพธ์ที่เลือกไว้ ก่อนที่จะเรียกสูตรอาหารว่า "ทดสอบแล้ว"

<a id="what-makes-a-strong-kling-video-prompt"></a>
## อะไรทำให้วิดีโอแจ้งของ Kling แข็งแกร่ง

เขียนข้อความที่เป็นประโยชน์ เช่น ชุดคำสั่งสั้นๆ ในการถ่ายทำ แทนที่จะเขียนรายการคำคุณศัพท์ที่มองเห็นได้

```text
[ผลลัพธ์]
ระยะเวลา อัตราส่วนภาพ ถ่ายครั้งเดียวหรือหลายช็อต ตั้งใจให้เสร็จสิ้น

[วัตถุประสงค์ของการอ้างอิงแต่ละรายการ]
ภาพที่ 1 กำหนดเอกลักษณ์ของตัวละคร ภาพที่ 2 กำหนดรูปร่างของผลิตภัณฑ์ การอ้างอิงการเคลื่อนไหวจะควบคุมการเคลื่อนไหวเท่านั้น

[คุณสมบัติที่ต้องคงเหมือนเดิม]
ตั้งชื่อเรื่อง รักษาใบหน้า ผม ภาพเงา และเสื้อผ้าให้ไม่เปลี่ยนแปลง รักษารูปร่าง วัสดุ และสีของผลิตภัณฑ์และเสาให้ไม่เปลี่ยนแปลง

[ฉาก]
สถานที่ เวลา สภาพอากาศ แหล่งกำเนิดแสงที่มองเห็นได้ และตำแหน่งเริ่มต้น

[ตั้งเวลาถ่าย]
0–{x}s — ขนาดช็อต มุมกล้อง และการเคลื่อนไหว การกระทำหลักอย่างหนึ่งและผลทางกายภาพของมัน
{x}–{y}s — การดำเนินการถัดไป การกระทำหลักประการหนึ่ง ผลลัพธ์ของมัน และภาพสุดท้ายที่จงใจเลือก

[การแสดงและฟิสิกส์]
การจ้องมอง การหายใจ มือ น้ำหนัก ความเฉื่อย การสัมผัส เสื้อผ้า ของเหลว และปฏิกิริยาสิ่งแวดล้อม

[เสียง]
ตั้งชื่อตัวละครที่พูดและระบุบรรทัด ภาษา และน้ำเสียงที่ถูกต้อง ระบุเสียงพื้นหลัง เสียงการกระทำที่ซิงโครไนซ์ และเวลาที่เพลงเริ่มหรือหยุด

[ความต่อเนื่อง / หลีกเลี่ยง]
รายการสิ่งที่จะต้องไม่เปลี่ยนแปลง หลีกเลี่ยงการเปลี่ยนแปลงข้อมูลประจำตัว วัตถุที่ซ้ำกัน ข้อความ โลโก้ และลายน้ำที่ไม่ถูกต้อง
```

อ่าน [Kling วิดีโอพร้อมวิศวกรรม](docs/PROMPT-GUIDE.md) สำหรับวิธีการที่สมบูรณ์และบันไดวนซ้ำ

<a id="image-to-video-checklist"></a>
## รายการตรวจสอบภาพต่อวิดีโอ

- รักษาเอกลักษณ์ของตัวละคร เสื้อผ้า รูปร่างของผลิตภัณฑ์ จำนวนวัตถุ องค์ประกอบ และทิศทางของแสงหลักไม่เปลี่ยนแปลง
- ให้แต่ละข้อมูลอ้างอิงมีจุดประสงค์เดียว อย่าขอให้ทุกการอ้างอิงควบคุมทุกอย่าง
- แยกการเคลื่อนไหวของวัตถุ การเคลื่อนไหวของสิ่งแวดล้อม และการเคลื่อนไหวของกล้อง
- อธิบายจุดเริ่มต้น เส้นทาง ความเร็ว และจุดหยุดสุดท้ายของกล้อง
- รักษาการสัมผัสของมือ น้ำหนัก ความเฉื่อย การสะท้อนและเงา
- สงวนเวลาหนึ่งหรือสองวินาทีสุดท้ายสำหรับการชะลอความเร็วและเฟรมสุดท้ายที่ใช้งานได้
- เพิ่มบทสนทนา บรรยากาศ โฟลีย์ และดนตรีเป็นเลเยอร์เสียงที่แยกจากกัน
- ใช้บุคคล ผลิตภัณฑ์ เพลง ฟุตเทจ และสถานที่ที่เป็นต้นฉบับหรือได้รับอนุญาต

## Kling พร้อมท์คำถามที่พบบ่อย

<a id="what-is-a-kling-video-prompt"></a>
### วิดีโอแจ้งของ Kling คืออะไร

ข้อความแจ้ง Kling ที่ดีคือชุดคำสั่งสั้นๆ ในการถ่ายทำ กำหนดผลลัพธ์ วัตถุประสงค์ในการอ้างอิง ลักษณะคงที่ เค้าโครงฉาก การกระทำตามกำหนดเวลา การเคลื่อนไหวของกล้อง การแสดง ฟิสิกส์ เสียง และปัญหาเฉพาะที่ควรหลีกเลี่ยง

<a id="should-i-use-text-to-video-or-image-to-video"></a>
### ฉันควรใช้ข้อความเป็นวิดีโอหรือรูปภาพเป็นวิดีโอ

ใช้การแปลงข้อความเป็นวิดีโอเพื่อค้นหาภาพจากแนวคิดหรือสคริปต์ ใช้ภาพเป็นวิดีโอเมื่อผลิตภัณฑ์ บุคคล ภาพประกอบ องค์ประกอบ หรือเฟรมแรกต้องยังคงจดจำได้ ใช้เฟรมเริ่มต้น/สิ้นสุดเมื่อปลายทางมีความสำคัญพอๆ กับการเปิด

<a id="how-do-i-keep-a-person-or-product-consistent"></a>
### ฉันจะรักษาบุคคลหรือผลิตภัณฑ์ให้สอดคล้องกันได้อย่างไร

เลือกหัวข้อหลักและระบุคุณลักษณะที่ต้องไม่เปลี่ยนแปลง แนบข้อมูลอ้างอิงที่ตรงกันเมื่อได้รับการสนับสนุน ระบุว่าการออกแบบ จำนวนชิ้นส่วน ฉลาก และเอกลักษณ์จะต้องไม่เปลี่ยนแปลง ทดสอบความสม่ำเสมอก่อนที่จะเพิ่มเอฟเฟกต์ที่ซับซ้อน

<a id="can-prompts-be-written-in-different-languages"></a>
### สามารถเขียนข้อความแจ้งเป็นภาษาต่าง ๆ ได้หรือไม่?

ใช่. โปรเจ็กต์นี้มีการแปล README ฉบับสมบูรณ์ใน 15 ภาษา บทสนทนาดั้งเดิมของ Kling 3.0 ที่ได้รับการรับรองได้รับการบันทึกเป็นภาษาจีน อังกฤษ ญี่ปุ่น เกาหลี และสเปน รักษาภาษา ผู้พูด น้ำเสียง และเจ้าของประโยคให้ชัดเจน จากนั้นตรวจสอบการออกเสียงและถ้อยคำ

<a id="are-the-prompts-free-to-use"></a>
### ข้อความแจ้งใช้งานได้ฟรีหรือไม่

พื้นที่เก็บข้อมูลถูกปล่อยภายใต้ [MIT](LICENSE). ผลลัพธ์ที่สร้างขึ้นยังคงเกี่ยวข้องกับสิทธิ์ที่แยกจากกันสำหรับผู้คน เสียง เพลง เครื่องหมายการค้า รูปภาพต้นฉบับ สถานที่ การอ้างสิทธิ์ และแพลตฟอร์มโมเดลที่ใช้

<a id="is-kling-40-available-now-and-can-it-generate-30-seconds"></a>
### Kling 4.0 พร้อมใช้งานแล้วและสามารถสร้าง 30 วินาทีได้หรือไม่

**Kling 4.0 Flash อยู่ในช่วงทดลองใช้ก่อนเปิดตัว** สำหรับสมาชิก Ultra Yearly ณ วันที่ 28 กันยายน 2026 Kling AI วางแผนโมเดล 4.0 เต็มรูปแบบและการเข้าถึง API ในเดือนตุลาคม โดยไม่มีวันเปิดตัวที่แน่นอน ของมัน **สูงสุด 30 วินาทีคือความสามารถเจเนอเรชันเดียวที่ประกาศไว้ของรุ่นเต็ม**. อย่าคิดว่าปัจจุบันนี้มีให้บริการในรูปแบบ Flash หรือผ่านผู้ให้บริการทุกราย สูตรอาหาร 52 รายการที่มีอยู่จะใช้เวลา 5–15 วินาทีและสามารถขยายเป็นไทม์ไลน์ที่ยาวขึ้นได้หลังจากใช้การควบคุมของโมเดลตัวเต็มแล้ว
