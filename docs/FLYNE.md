## From a recipe to a useful draft

1. Pick one of the [52 inherited recipes](../prompts/README.md) or [four additional exercises](../prompts/inherited-flash-exercises.md).
2. Replace the subject, location and prop details. Keep the action order and camera path clear.
3. Open the Flyne AI page. Read the selected model, duration, ratio, resolution and cost before submitting.
4. If the available duration is shorter than the recipe, use fewer beats. For example, turn the 15-second bicycle-light starter into a 5-second test: show the already-mounted lamp, press its switch, hold on the beam. Do not squeeze four actions into five seconds.
5. Use only the input controls actually available. If there is no element-reference or multi-shot control, test a single subject and single take first. Do not paste unsupported API-style parameters.
6. Add dialogue after the image and motion work. Keep one speaker per line; review pronunciation and mouth motion.
7. Record the actual model and provider with the result. A Turbo draft remains a Turbo result when linked from a 4.0 guide.

## Keep an iteration log

Copy [the test record template](TEST-RECORD.md). Keep the prompt, reference roles, settings, output link and visible failures together. Change one variable at a time: subject consistency → action → camera → sound. A scene that looks good once is not a guaranteed capability.
