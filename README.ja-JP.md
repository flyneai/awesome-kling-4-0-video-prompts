<a id="what-is-included"></a>
## 含まれるもの

- **1 行の断片ではなく、52 の完全なプロンプト:** 各プロンプトには、モデル モード、固定キャラクターとオブジェクトの特性、シーン レイアウト、時間制限付きアクション、演技、サウンド、回避すべきエラーが含まれます。
- **13 のプロダクション コレクション:** 映画、ダイアログ、リファレンス コントロール、編集、製品、ライブストリーム、UGC、自動車、工業用、アクション、VFX、アニメーション、縦型ドラマ、バイラル ソーシャル、モーション グラフィックス、トランジション、サウンド シンク、食品、旅行、学習、ペット、ゲーム、再利用可能なプロダクション プレート。
- **4 つの制御戦略:** テキスト主導の発見、画像からビデオへの変換、開始/終了フレームの遷移、要素/参照の一貫性。
- **文書化された 5 つの Kling 3.0 ネイティブ対話言語:** 中国語、英語、日本語、韓国語、スペイン語（混合言語の例を含む）。フル 4.0 では、より広範な言語サポートが約束されています。
- **15 のプロジェクト言語:** ローカライズされたナビゲーションとクイックスタート ガイダンス。ドキュメントとモデル音声サポートを明確に区別します。
- **6 つのローカルビジュアルアセット:** Flyne AI のカバーと 5 つのシーン参照画像。 [アセットマニフェスト](assets/images/README.md).
- **制作指導：** アスペクト比、カメラの位置、参考資料の権利、音声タイムライン、改訂記録と出版前のチェック。
- **Flash クリエイターのウォッチリスト:** 18 個のリンクされた X ケース (10 個が継承、8 個が追加)、4 個の継承されたエクササイズ、6 個の Flyne AI エクササイズ、および自転車ライト スターター。
- **Flyne AI ワークフローのメモ:** 選択したモデルを生成前にチェックするブラウザー ワークフロー。

| Kling 4.0 Flash | **早期アクセスは 2026 年 9 月 28 日に開始されました** Ultra Yearly定期購読者向け | アカウントで利用可能なコントロールをテストします。 4.0 の完全な制限がフラッシュに適用されるとは想定しないでください |

## Kling 4.0 Flash: X デモと即時レッスン

チェックオン済み **2026 年 9 月 29 日**。の [Kling AI X の公式発表ビデオ](https://x.com/Kling_ai/status/2104596718067257458) 4.0 ファミリと Flash 早期アクセスを導入します。そのプロモーション用モンタージュは **ない** Flash が 1 回のリクエストで 1:54 ビデオを生成できるという証拠です。これらの投稿では、公式ベンチマークや当社の独立したテストではなく、作成者独自のテストについて説明しています。オリジナルのビデオを見て、その作成者をクレジットしてください。このリポジトリは、映像やプロンプト全体をコピーしません。

| クリエイターの X 投稿 | 共有されたもの | 役立つ即時実験 |
|---|---|---|

**Flash 指向のスターター プロンプト (15 秒、9:16):** これは、52 プロンプトのカタログ外のテストされていない演習であり、 *テスト方法* ただし、X プロンプトからコピーされたものではありません。選択した Flash モードで利用可能なコントロールのみを使用してください。

```text
[件名/参考文献]
修理工場の作業台に置かれた、ノーブランドの小さな充電式自転車ランプ。画像が指定されている場合、ランプの形状、マットグラファイト仕上げ、および単一の琥珀色のスイッチのみが制御されます。ランプは常に 1 つだけにしておきます。

[シーン/カメラ]
夕暮れの静かな自転車工場。整備士の手からランプ、そして自転車のハンドルバーに至るまで、連続的にカメラが動きます。窓からの自然光。カットやテレポートはありません。

[タイミング]
0 ～ 4 秒: 整備士はオフになったランプをハンドルバーの横に置きます。両手と取り付けブラケットを示します。
4 ～ 8 秒: 彼女はランプをブラケットにクリップで留めます。クリップが音を立ててロックされて初めて、彼女の親指がオレンジ色のスイッチを押します。
8 ～ 12 秒: ライトが 1 回点灯し、フロント タイヤとフロアの小さな部分が照らされます。カメラが横に傾いてビームが現れます。
12 ～ 15 秒: 彼女はハンドルバーを放します。ランプは固定されたままです。自転車とライトの最終フレームをしっかりと保持します。

[オーディオ / 制約]
静かなワークショップの背景音、取り付けクリップのクリック 1 回とスイッチのクリック 1 回。スピーチや音楽はありません。ランプの形状、針の数、取付位置、点灯方向は変わりません。ブランド名、余分なランプ、説明できないカットはありません。
```

フラッシュの場合、 **短い指示文** そして **長くても構成の明確な指示文** どちらもテストする価値があります。決定要因は、すべての文が目に見える決定を制御するか、それとも聞こえる決定を制御するかです。レシピを「テスト済み」と呼ぶ前に、選択したモード、期間、参照、結果を記録します。

<a id="what-makes-a-strong-kling-video-prompt"></a>
## Kling のビデオ プロンプトが強力になるのはなぜですか?

視覚的な形容詞のリストではなく、短い撮影手順のような役立つプロンプトを作成します。

```text
[出力]
長さ、アスペクト比、シングルテイクまたはマルチショット、意図した仕上がり。

[各参照の目的]
画像 1 はキャラクターのアイデンティティを定義します。画像 2 は製品の形状を定義します。移動参照は移動のみを制御します。

[変わらなくてはいけない機能]
件名に名前を付けます。顔、髪、シルエット、服装は変更しないでください。製品と支柱の形状、素材、色は変更しないでください。

[シーン]
場所、時間、天候、可視光源、開始位置。

[タイムショット]
0–{x}s — ショットのサイズ、カメラの角度、動き。 1 つの主要なアクションとその物理的影響。
{x}–{y}s — 次のアクション。 1 つの主要なアクション、その結果、および意図的に選択された最終イメージ。

[演技と体力]
視線、呼吸、手、重さ、慣性、接触、布地、液体、環境の反応。

[オーディオ]
話しているキャラクターの名前を指定し、正確なセリフ、言語、口調を指定します。背景音、同期アクション音、音楽の開始または停止のタイミングを指定します。

【継続・回避】
決して変えてはいけないものを列挙します。 ID の変更、オブジェクトの重複、不正なテキスト、ロゴ、透かしを避けてください。
```

<a id="image-to-video-checklist"></a>
## 画像からビデオへのチェックリスト

- キャラクターのアイデンティティ、服装、製品の形状、オブジェクトの数、構成、主な光の方向を変更しないでください。
- それぞれの参照入力に 1 つの目的を与えます。すべてを制御するためにすべての参照を要求しないでください。
- 被写体の動き、環境の動き、カメラの動きを分離します。
- カメラの開始点、経路、速度、最終停止点を説明します。
- 手の接触、重量、慣性、反射、影を維持します。
- 最後の 1 ～ 2 秒は減速と使用可能な最終フレームのために確保してください。
- ダイアログ、アンビエンス、フォーリー、音楽を個別のオーディオ レイヤーとして追加します。
- オリジナルまたはライセンスを取得した人物、製品、音楽、映像、場所を使用します。

<a id="kling-prompt-faq"></a>
## クリングプロンプトに関するよくある質問

<a id="what-is-a-kling-video-prompt"></a>
### Kling ビデオ プロンプトとは何ですか?

優れた Kling プロンプトは、短い撮影手順のセットです。出力、参照目的、固定特性、シーン レイアウト、時間指定アクション、カメラの動き、演技、物理学、サウンド、および回避すべき特定の問題を定義します。

<a id="should-i-use-text-to-video-or-image-to-video"></a>
### テキストからビデオへの変換と画像からビデオへの変換を使用する必要がありますか?

コンセプトやスクリプトから視覚的に発見するには、テキストからビデオへの変換を使用します。製品、人物、イラスト、構図、または最初のフレームを認識可能な状態にしておく必要がある場合は、画像からビデオへの変換を使用します。開始フレームと同じくらい目的地が重要な場合は、開始/終了フレームを使用します。

<a id="how-do-i-keep-a-person-or-product-consistent"></a>
### 人や製品の一貫性を保つにはどうすればよいですか?

主要な主題を選択し、変更しない必要がある特性をリストします。サポートされている場合は、一致する参照を添付します。デザイン、部品数、ラベル、およびアイデンティティを変更してはいけないことを明記します。複雑なエフェクトを追加する前に一貫性をテストしてください。

<a id="can-prompts-be-written-in-different-languages"></a>
### プロンプトを別の言語で記述することはできますか?

はい。このプロジェクトでは、完全な README 翻訳を 15 か国語で提供します。 Kling 3.0 のネイティブ ダイアログが中国語、英語、日本語、韓国語、スペイン語で文書化されていることを確認しました。言語、話者、口調、セリフの所有権を明示的に保ち、発音と言葉遣いを確認します。

<a id="are-the-prompts-free-to-use"></a>
### プロンプトは無料で使用できますか?

リポジトリは以下の下でリリースされます。 [MIT](LICENSE)。生成された出力には、人物、音声、音楽、商標、ソース画像、場所、クレーム、使用されるモデル プラットフォームに対する個別の権利が含まれる場合があります。

<a id="is-kling-40-available-now-and-can-it-generate-30-seconds"></a>
### Kling 4.0 は現在利用可能ですか? 30 秒を生成できますか?

**Kling 4.0 Flash は早期アクセス中です** Kling AI は、正確な発売日は未定ですが、10 月に完全な 4.0 モデルと API アクセスを計画しています。その **最大 30 秒は、フルモデルの 1 世代の性能として発表されています。**。現在、Flash やすべてのプロバイダーを通じて利用できるとは考えないでください。既存の 52 のレシピは 5 ～ 15 秒ですが、完全なモデルのコントロールが利用可能になった後は、より長いタイムラインに拡張できます。

## FLAQ AI Kling 4.0 API · Kling 3.0 Std / Pro

アプリに動画生成を組み込む場合は、FLAQ AI の Kling API をご検討ください。

- [Kling 4.0 API · テキストから動画](https://flaq.ai/models/kuaishou/kling-4-0-text-to-video/) — 場面を文章で指定して動画を作る機能。広告、SNS 動画、物語のアイデアに使えます。
- [Kling 4.0 API · 画像から動画](https://flaq.ai/models/kuaishou/kling-4-0-image-to-video/) — 参考画像と動きの指示を組み合わせ、商品写真、人物写真、イラストを動かす機能です。

2026年9月30日確認：両ページとも **Coming Soon（近日公開）** と表示されています。API のモデル紹介ページです。提供開始、パラメーター、料金は公開後の案内をご確認ください。

- [Kling 3.0 Std API](https://flaq.ai/models/kuaishou/kling-3-0-std-text-to-video/) — テキストから動画を生成。費用を抑えた試作や複数案の制作に。
- [Kling 3.0 Pro API](https://flaq.ai/models/kuaishou/kling-3-0-pro-text-to-video/) — 画質を重視する制作向け。同じプロンプトで Std と比較して選んでください。

[API の選び方と導入ガイド（英語 / 中国語）](docs/FLAQ-AI.md)
