## 무엇이 포함되어 있나요?

- **한 줄의 단편이 아닌 완전한 프롬프트 52개:** 각 프롬프트에는 모델 모드, 고정된 캐릭터 및 개체 특성, 장면 레이아웃, 시간 제한 동작, 연기, 소리 및 피해야 할 오류가 포함됩니다.
- **13개의 프로덕션 컬렉션:** 영화, 대화, 참조 제어, 편집, 제품, 라이브스트림, UGC, 자동차, 산업, 액션, VFX, 애니메이션, 수직 드라마, 바이럴 소셜, 모션 그래픽, 전환, 사운드 동기화, 음식, 여행, 학습, 애완동물, 게임 및 재사용 가능한 제작 플레이트.
- **네 가지 제어 전략:** 텍스트 기반 검색, 이미지-비디오, 시작/끝 프레임 전환 및 요소/참조 일관성.
- **5개의 문서화된 Kling 3.0 모국어 대화 언어:** 중국어, 영어, 일본어, 한국어, 스페인어(혼합 언어 예시 포함) 전체 4.0은 더 광범위한 언어 지원을 약속합니다.
- **15개 프로젝트 언어:** 문서화와 모델 음성 지원을 투명하게 구분하여 현지화된 탐색 및 빠른 시작 안내를 제공합니다.
- **6개의 로컬 시각적 자산:** Flyne AI 표지와 5개의 장면 참조 이미지가 문서화되어 있습니다. [자산 매니페스트](assets/images/README.md).
- **생산 지침:** 화면 비율, 카메라 위치, 참조 자료 권한, 오디오 타임라인, 수정 기록 및 게시 전 확인 사항입니다.
- **플래시 제작자 관심 목록:** 18개의 연결된 X 사례(10개의 상속, 8개의 추가), 4개의 상속된 운동, 6개의 Flyne AI 운동 및 자전거 라이트 스타터.
- **Flyne AI 워크플로우 참고사항:** 생성하기 전에 선택한 모델을 확인하는 브라우저 워크플로입니다.

## 모델 상태 및 호환성

Kling 4.0가 발표되었습니다. Flash 버전은 초기 액세스 단계에 있습니다. 정식 버전은 나중에 계획되어 있습니다. 각 프롬프트를 귀하의 계정에서 실제로 선택한 모델에 맞게 조정하세요.

| 목 | 확인된 상태 | 이 라이브러리가 기능을 처리하는 방법 |
|---|---|---|
| Kling 4.0 Flash | **얼리 액세스는 2026년 9월 28일에 오픈되었습니다.** Ultra 연간 가입자의 경우 | 귀하의 계정에서 사용 가능한 제어 기능을 테스트하십시오. 플래시에 전체 4.0 제한이 적용된다고 가정하지 마세요. |
| 풀 클링 4.0 | **2026년 10월에 발표됨**; 정확한 날짜는 게시되지 않았습니다. | 전체 모델을 테스트할 수 있을 때까지 발표된 기능을 계획대로 처리하십시오. |
| 세대 요청당 비디오 기간 | 비디오 3.0: 최대 **15초**; 전체 4.0: **최대 30초 발표** | 52개의 기존 프롬프트 타임라인은 5~15초로 유지됩니다. 선택한 모델이 더 긴 클립을 지원하는 경우에만 비트 확장 |

```text
[주제/참고자료]

[장면/카메라]

[타이밍]

4~8초: 램프를 브래킷에 끼웁니다. 클립이 잠기는 소리가 들린 후에야 엄지손가락으로 황색 스위치를 누릅니다.
8~12초: 조명이 한 번 켜지고 앞 타이어와 바닥의 작은 부분을 비춥니다. 카메라가 옆으로 움직여 빔을 드러냅니다.
12~15초: 핸들바를 놓습니다. 램프는 고정되어 있습니다. 자전거와 라이트에 최종 프레임을 안정적으로 고정합니다.
```

## 강력한 Kling 비디오 메시지를 만드는 이유는 무엇입니까?

시각적 형용사 목록보다는 짧은 촬영 지침 세트와 같은 유용한 프롬프트를 작성하세요.

```text
[출력]
지속 시간, 화면 비율, 싱글 테이크 또는 멀티 샷, 의도한 마무리.

[각 참고문헌의 목적]
이미지 1은 캐릭터의 정체성을 정의합니다. 이미지 2는 제품의 모양을 정의합니다. 이동 참조는 이동만 제어합니다.

[동일하게 유지되어야 하는 기능]
주제의 이름을 지정하십시오. 얼굴, 머리카락, 실루엣, 의상은 그대로 유지하세요. 제품과 소품의 모양, 소재, 색상을 그대로 유지하세요.

[장면]
위치, 시간, 날씨, 가시광선 및 시작 위치.

[시간 제한 촬영]
0–{x}s — 샷 크기, 카메라 각도 및 움직임; 하나의 주요 행동과 그 물리적 결과.
{x}–{y}s — 다음 작업; 하나의 주요 행동, 그 결과 및 의도적으로 선택한 최종 이미지.

[연기 및 물리학]
시선, 호흡, 손, 무게, 관성, 접촉, 천, 액체 및 환경 반응.

[오디오]
말하는 캐릭터의 이름을 지정하고 정확한 대사, 언어 및 톤을 제공하세요. 배경음, 동기화된 동작음, 음악 시작 또는 중지 시기를 지정합니다.

[연속성 / 회피]
절대 변하지 말아야 할 것을 나열하십시오. ID 변경, 개체 중복, 잘못된 텍스트, 로고 및 워터마크를 피하세요.
```

## 언어 및 현지화

프로젝트는 README 번역을 다음과 같이 정렬했습니다. **15개 언어**:

- 영어, 중국어 간체, 중국어 번체, 일본어, 한국어;
- 스페인어, 프랑스어, 독일어, 브라질 포르투갈어, 이탈리아어;
- 아랍어, 러시아어, 인도네시아어, 태국어, 베트남어.

표준 프롬프트 파일은 영어로 유지되므로 복잡한 타이밍과 카메라 지침이 자동으로 분기되지 않습니다. 모든 현지화된 README는 모델 상태, X 예제, 프롬프트 템플릿, 그림 하이라이트, 전체 카탈로그, 체크리스트, FAQ, API 권장 사항 및 제휴 정보 등의 영어 페이지를 따릅니다. 52개의 링크된 레시피 파일은 영어로 남아 있습니다. 이 페이지의 두 프롬프트 블록이 번역되었습니다. 참조 [언어 매트릭스 및 현지화 규칙](docs/LANGUAGES.md).

> 문서 언어 ≠ 기본 음성 지원. 검증된 클링 3.0 원어민 대화 목록에는 중국어, 영어, 일본어, 한국어, 스페인어가 포함되어 있습니다. Kling AI는 전체 4.0에 대한 광범위한 다국어 및 악센트 지원을 발표했습니다. 게시하기 전에 선택한 모드를 확인하고 생성된 음성을 검토하세요.

<a id="image-to-video-checklist"></a>
## 이미지-비디오 체크리스트

- 캐릭터 아이덴티티, 의상, 제품 모양, 개체 수, 구성 및 주요 조명 방향을 변경하지 않고 유지하세요.
- 각 참조 입력에 하나의 목적을 부여하십시오. 모든 것을 통제하기 위해 모든 참조를 요청하지 마십시오.
- 피사체 움직임, 환경 움직임, 카메라 움직임을 분리합니다.
- 카메라의 시작, 경로, 속도 및 최종 중지 지점을 설명합니다.
- 손 접촉, 무게, 관성, 반사 및 그림자를 보존합니다.
- 감속과 사용 가능한 최종 프레임을 위해 마지막 1~2초를 남겨두세요.
- 대화, 분위기, 폴리, 음악을 별도의 오디오 레이어로 추가하세요.
- 원본 또는 라이센스를 받은 사람, 제품, 음악, 영상 및 위치를 사용하십시오.

<a id="kling-prompt-faq"></a>
## 클링 프롬프트 FAQ

<a id="what-is-a-kling-video-prompt"></a>
### 클링 비디오 프롬프트란 무엇입니까?

좋은 Kling 프롬프트는 짧은 촬영 지침 세트입니다. 출력, 참조 목적, 고정 특성, 장면 레이아웃, 시간 제한 동작, 카메라 이동, 연기, 물리, 사운드 및 피해야 할 특정 문제를 정의합니다.

<a id="should-i-use-text-to-video-or-image-to-video"></a>
### 텍스트-비디오 또는 이미지-비디오를 사용해야 합니까?

개념이나 스크립트를 시각적으로 발견하려면 텍스트를 비디오로 변환하는 방법을 사용하세요. 제품, 사람, 일러스트레이션, 구성 또는 첫 번째 프레임을 인식할 수 있어야 하는 경우 이미지-비디오를 사용하세요. 목적지가 시작만큼 중요한 경우 시작/끝 프레임을 사용하세요.

<a id="how-do-i-keep-a-person-or-product-consistent"></a>
### 사람이나 제품의 일관성을 어떻게 유지합니까?

주요 주제를 선택하고 변하지 않아야 하는 특성을 나열하십시오. 지원되는 경우 일치하는 참조를 첨부하세요. 디자인, 부품 수, 라벨 및 ID가 변경되어서는 안 된다는 점을 명시합니다. 복잡한 효과를 추가하기 전에 일관성을 테스트하십시오.

<a id="can-prompts-be-written-in-different-languages"></a>
### 프롬프트를 다른 언어로 작성할 수 있나요?

예. 이 프로젝트는 15개 언어로 완전한 README 번역을 제공합니다. 검증된 Kling 3.0 기본 대화는 중국어, 영어, 일본어, 한국어 및 스페인어로 문서화되어 있습니다. 언어, 화자, 톤 및 대사 소유권을 명시적으로 유지한 다음 발음과 표현을 확인합니다.

<a id="are-the-prompts-free-to-use"></a>
### 프롬프트는 무료로 사용할 수 있나요?

저장소는 다음과 같이 릴리스됩니다. [MIT](LICENSE). 생성된 출력물에는 사람, 음성, 음악, 상표, 소스 이미지, 위치, 주장 및 사용된 모델 플랫폼에 대한 별도의 권리가 포함될 수 있습니다.

<a id="is-kling-40-available-now-and-can-it-generate-30-seconds"></a>
### 현재 Kling 4.0을 사용할 수 있나요? 30초를 생성할 수 있나요?

**Kling 4.0 Flash가 얼리 액세스 단계에 있습니다.** 2026년 9월 28일부터 Ultra 연간 가입자에게 적용됩니다. Kling AI는 정확한 출시일 없이 10월에 전체 4.0 모델 및 API 액세스를 계획하고 있습니다. 그것은 **최대 30초는 발표된 전체 모델의 단일 세대 기능입니다.**. 현재 Flash나 모든 공급자를 통해 사용할 수 있다고 가정하지 마십시오. 기존 52개의 레시피는 5~15초이며 전체 모델 제어가 가능해지면 더 긴 타임라인으로 확장될 수 있습니다.
